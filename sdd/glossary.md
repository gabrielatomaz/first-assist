# FIRST Assist — Glossary

This document defines domain-specific terms used throughout the FIRST Assist application, academic paper, and SDD documentation.

## Domain Terms

| Term | Definition |
| --- | --- |
| **FRC** | FIRST Robotics Competition. A global high-school robotics program where teams build industrial-sized robots. |
| **FTA** | FIRST Technical Advisor. A key volunteer responsible for the overall technical operation of the field, including network wireless connectivity and FMS integrity. |
| **CSA** | Control System Advisor. A volunteer who assists teams in diagnosing and resolving control system issues on their robots. |
| **FMS** | Field Management System. The centralized network system that controls match play, robot states, and scores. |
| **Incident** | A technical issue reported during an event that affects a team's performance, communication, or electronics. |
| **Match** | A single round of play on the field, which can be a qualification match or playoff match. |
| **Team Number** | A unique number assigned by FIRST to identify an FRC team (e.g., 254, 1772). |
| **AI Suggestion** | Diagnostic advice generated automatically based on incident descriptions using a Large Language Model (LLM). |
| **Knowledge Base** | A searchable archive containing resolved incidents, their root causes, and their applied solutions. |
| **PWA** | Progressive Web Application. A web app that acts like a native application, supporting offline modes, service workers, and home screen installation. |
| **DSR** | Design Science Research. The research methodology used to design, build, and evaluate the FIRST Assist software artifact. |
| **JWT** | JSON Web Token. A secure method of representing claims to transfer authentication information. |
