# Project Vision — FIRST Assist

## Purpose
During FIRST Robotics Competition (FRC) events, technical volunteers (FTAs and CSAs) are tasked with maintaining field performance and assisting teams. Robots often lose connection, blow fuses, or experience software crashes. Under strict timelines, documenting these issues and collaborating on solutions is difficult. 

**FIRST Assist** is a Progressive Web Application (PWA) designed to solve this by:
1. Centralizing real-time incident reporting (including fast hands-free voice reports).
2. Coordinating field operations between FTAs (reporters) and CSAs (resolving technicians).
3. Utilizing Artificial Intelligence (LLM) to suggest solutions using natural language inputs.
4. Preserving resolved tickets in a searchable Knowledge Base to accelerate troubleshooting in future matches.

## Academic Significance
This project serves as a university final-year paper using the **Design Science Research (DSR)** methodology. DSR focus areas:
* **Conscientização (Awareness)**: Identifying the communication bottleneck between field supervisors and support technicians.
* **Sugestão (Suggestion)**: Proposing a collaborative, mobile-first Web application with AI assistance.
* **Desenvolvimento (Development)**: Building the Vue + Node + MongoDB PWA.
* **Avaliação (Evaluation)**: Evaluating the system's impact on ticket resolution times.
* **Conclusão (Conclusion)**: Documenting contributions to the FRC community.
